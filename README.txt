PDF Data Extractor Tool
=======================

This tool extracts table data from PDF files and converts non-standard Kruti Dev Hindi text into proper Unicode Hindi text, saving it into Excel (.xlsx) and CSV (.csv) formats.

Prerequisites:
--------------
You MUST have Python installed on your Windows machine to run this.
1. Download Python from: https://www.python.org/downloads/
2. Run the installer.
3. IMPORTANT: At the bottom of the installer window, check the box that says "Add Python to PATH" before clicking Install!

How to use:
-----------
1. Put the PDF file you want to extract into this folder (the same folder as this README.txt).
2. Double-click the "run_extractor.bat" file.
3. The first time you run it, it will take a minute or two to automatically set up its environment and install the required tools.
4. Follow the prompts in the black command window:
   - Type the name of your PDF file (e.g., my_document.pdf) and press Enter.
   - Type what you want to name your output files (e.g., extracted_data) and press Enter.
5. Wait for the extraction to finish. You will find the Excel and CSV files saved in this folder!

Troubleshooting:
----------------
If the script closes immediately or says Python is not found, reinstall Python and make sure to check "Add Python to PATH".
